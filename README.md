# 🌍 Terre Future

Simulation interactive de l'évolution de la Terre sur une période allant de 2026 à 1 000 000.

## Fonctionnalités

- 🌍 Globe 3D
- 🧩 Plaques tectoniques
- 🌋 Volcanisme simplifié
- 🌎 Séismes probabilistes
- 🌊 Tsunamis conditionnels
- ☄️ Impacts d'astéroïdes
- 🌡️ Scénarios climatiques
- 📅 Simulation temporelle 2026 → 1 000 000
- 📱 Interface mobile
- 🖥️ Compatible ordinateur
- 🔬 Distinction entre modèle scientifique et extrapolation

## Important

Cette application est une simulation pédagogique.

Elle ne prédit pas les dates réelles des séismes, tsunamis,
éruptions volcaniques ou impacts d'astéroïdes.

Les paramètres utilisés sont simplifiés et certaines
projections deviennent extrêmement incertaines sur de très
longues périodes.
